# FitLog — Fitness & Workout Planner

FitLog is a modern fitness and workout planning web application that helps users discover exercises, create a personalized workout plan, save exercises for later, and track their daily workout activities. The application provides a clean, responsive interface designed to make workout planning simple and convenient.

## 📌 Project Description

FitLog allows users to explore different workout exercises and manage their personal fitness plans. Users can add exercises to their today's plan, save exercises for later, view exercise details, track workout statistics, and organize their plan using sorting options.

The application is built with modern React and Next.js technologies and provides a responsive experience across desktop, tablet, and mobile devices.

## 🛠️ Technologies Used

* **Next.js** — React framework for building the application
* **React** — Building reusable UI components
* **TypeScript** — Type-safe development
* **Tailwind CSS** — Responsive and modern styling
* **DaisyUI** — Pre-built UI components
* **React Icons** — Icons throughout the application
* **React Toastify** — Success and notification messages
* **Context API** — Global state management
* **REST API** — Fetching workout and exercise data

## ✨ Features

### 1. 🏋️ Explore Exercises

Users can browse different workout exercises with useful information such as:

* Exercise name
* Equipment
* Duration
* Calories burned
* Rating
* Exercise image

### 2. 📋 Create Today's Workout Plan

Users can add exercises to their personal workout plan and manage the exercises they want to complete today.

### 3. 🔖 Save Exercises for Later

Users can save interesting exercises for later without immediately adding them to their workout plan.

### 4. 📊 Workout Statistics

The My Plan page automatically displays workout statistics including:

* Total exercises
* Total workout minutes
* Total calories

### 5. 🔀 Sort Workout Exercises

Users can organize their workout exercises using different sorting options:

* Duration
* Calories
* Rating

### 6. ❌ Remove Exercises

Users can easily remove exercises from either their workout plan or saved list.

### 7. 👀 View Exercise Details

Each exercise has a dedicated details page where users can view more information about the selected workout.

### 8. 📱 Fully Responsive Design

The application is designed to work smoothly on:

* Mobile devices
* Tablets
* Laptops
* Desktop screens

### 9. 🔔 User Notifications

React Toastify provides instant feedback when users perform actions such as adding, saving, or removing exercises.

### 10. 🧩 Reusable Components

The application is organized using reusable React components, making the code easier to maintain and extend.
